# Inkray Backend

This directory is reserved for Inkray's future Python + FastAPI + PyTorch inference service.

## Planned Responsibilities

- Monocular geometry reconstruction using **MoGe-3** (depth maps, surface normals, 3D point maps, and camera intrinsics).
- Intrinsic image decomposition using **Marigold IID Lighting** (albedo, shading, and residual layers).
- Interactive surface segmentation using **SAM 2**.

## Current Status

**Not yet implemented.** Only the directory scaffold and package metadata are present. The frontend image loading and viewport run client-side without requiring a backend.
